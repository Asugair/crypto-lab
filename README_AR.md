# crypto-lab · حزمة تشغيل تجربة الـ100 دولار

**الغرض:** أي وكيل (Opus، Sonnet، Claude Code) يقرأ `SKILL.md` وينفذ دورة كاملة بنفس القواعد، بلا مفاتيح ولا محافظ ولا خدمات مدفوعة. لا يتداول ولا يسجل صفقات تلقائيًا.

## المحتويات
- `rules.json` قواعد التجربة وفلاتر الاكتشاف وبوابات المخاطر وافتراضات التكلفة. المصدر الوحيد للقواعد.
- `scripts/discover.py` أزواج سولانا الجديدة من واجهة GeckoTerminal العامة، فلترة 1 إلى 24 ساعة، حد سيولة/حجم/صفقات، حتى 3 مرشحين.
- `scripts/risk.py` فحص العقد عبر RPC عام: صلاحيات mint/freeze، Token-2022 وامتداداته، تركيز أكبر 20 حامل مع فصل محافظ المجمعات، وجود بيع مرصود. أي فحص يفشل = غير متحقق.
- `scripts/cost.py` تكلفة ذهاب وعودة لمركز 10 دولارات (شبكة + منصة + انزلاق مقدر) ومقدار الحركة الإجمالية المطلوبة لصافي 5%. كله Estimate حتى يُقاس من شاشة عرض حقيقية.
- `scripts/snapshot.py` (24 سبتمبر) يسجّل سعر كل مرشح وقت اكتشافه، وكل فحص بعده يجيب السعر والسيولة الحاليين لمدة 7 أيام → `data/snapshots.json`. ملاحظات أسعار، مو صفقات.
- `scripts/markets.py` (24 سبتمبر) صناديق ETF متوافقة مع الشريعة حسب مُصدريها (SPUS وHLAL وUMMA) ومؤشرات البتكوين (السعر، متوسط 50 و200 يوم، مضاعف ماير، RSI، التذبذب، البعد عن القمة، مؤشر الخوف والطمع) → `data/markets.json`. للمقارنة فقط، مو إشارة دخول.
- فحص الحاملين التلقائي يحتاج مفتاح Helius مجاني كـ secret باسم `HELIUS_API_KEY` في إعدادات المستودع. بدونه يظل الفحص يدوي.
- `run.sh` الدورة كاملة → `data/latest.json`.
- `.github/workflows/scan.yml` تشغيل مجدول مجاني على GitHub Actions (4 مرات يوميًا) لأن بيئة الدردشة محجوبة عن هذه الواجهات. احذف الجدول بعد 30 سبتمبر (مُدّدت التجربة من 26 إلى 30 سبتمبر بتاريخ 24 سبتمبر).
- `templates/report_template.md` قالب التقرير العربي. `data/ledger.csv` السجل (يكتبه عبدالإله فقط). `data/decisions.jsonl` سلسلة القرارات.
- `tests/` بيانات وهمية لاختبار المنطق فقط.

## التشغيل خلال 5 دقائق
1. أنشئ مستودع GitHub وارفع المجلد كما هو.
2. Settings → Actions → General → Workflow permissions → Read and write.
3. Actions → crypto-lab scan → Run workflow. بعد دقيقة يظهر `data/latest.json`.
4. في أي محادثة مع Opus/Sonnet: الصق رابط raw للملف واطلب "شغّل crypto-lab" مع إرفاق SKILL.md (أو ثبّته كـ skill).

## ما تم اختباره فعليًا يوم 2026-09-17
- منطق الفلترة والأحكام والتكلفة على بيانات وهمية: يعمل.

## حدود صريحة
الحزمة لا تقرأ محافظ ولا توقّع ولا تقيس الانزلاق الحقيقي ولا تكشف كل أنواع honeypot. هذه مهام الجلسة المشتركة وشاشة العرض الحقيقية مفتوحة.
